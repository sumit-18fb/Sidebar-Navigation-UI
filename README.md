# Sidebar Navigation UI

A modern sidebar navigation UI created using HTML and CSS.

## 📌 About the Project

This project is a simple dashboard-style sidebar navigation design.

It includes:

- Dashboard
- Shortcut
- Overview
- Events
- About
- Services
- Contact
- Feedback
- Social media icons
- Hover effects
- Full-screen background image
- Transparent sidebar design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
